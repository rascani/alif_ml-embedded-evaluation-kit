Model: serialized graph, weights and constants. Operators: selected implementations/utilities, CMSIS-NN kernels and resolver/registry/dispatch bindings. Core runtime: interpreter/executor, allocation, planning and schema support.

Operator costs depend on the selected operator set and numeric variants; code can be shared across models. Core runtime is largely shared overhead, with some linker-dependent variation. The three columns sum to the previous flash subtotal before rounding.

Build-size caveat: the measured GCC builds disable function sections, retaining otherwise-unused functions. An isolated ET ResNet8 audit gives 31.42 KiB core with function sections, or 23.36 KiB with runtime-only -Os; logging stays on and kernels stay at -O3. These alternatives have no E8 timing results. TFLM uses the same function-section setting and needs an equivalent audit.

Measurement

Latency and cycles average 300 measured inferences per model/runtime across three boots. Cycles are averaged from raw measurements and rounded to the nearest whole cycle. Each boot: one separately timed first call, ten warm-ups, then 100 measured calls. Input preparation and UART reporting are outside timing; caches are not flushed.

The complete second ET pass passed all 36 saved-output checks. Earlier interrupted captures are retained separately. Independent hardware timer verification remains pending.

Memory scope

Flash: the three disjoint model, operators and core-runtime categories above. Excludes runner, diagnostics, fixtures, platform, adapter, shared support/strings and padding.

RAM: inference pools and persistent allocations; ET also includes attributed runtime static storage. Excludes unused reservations, stack high water, benchmark/platform state, diagnostics, initialization workspace and transient heap peaks. These are component costs, not whole-device requirements.

Current state: ET redundant input staging/copy removed; selective operators and primitives enabled (zero primitive registrations). DS-CNN still retains two DQ-to-Q pairs pending cleanup. Code/models: MRAM. Inference pools: SRAM. Globals/heap/stack: DTCM.
